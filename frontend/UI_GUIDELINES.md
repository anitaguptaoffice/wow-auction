# 艾泽拉斯交易所 UI 规范

采用 frontend-design skill，围绕魔兽拍卖行的查价任务维护克制的中性界面，以物品品质色和少量金色保留游戏识别。金色用于当前选择和可执行操作，物品品质色保留游戏语义。装饰不应降低行情表格的可读性。

## 视觉基线

| 用途 | 深色 | 浅色 |
| --- | --- | --- |
| 控件背景 | `#1b2027` | `#ffffff` |
| 菜单背景 | `#20262e` | `#ffffff` |
| 主文字 | `#f4f1e9` | `#262b33` |
| 辅助文字 | `#b4bac4` | `#646b77` |
| 控件边框 | `#586171` | `#cdd3de` |
| 选择强调 | `#f1cc72` | `#775400` |

正文与控件使用苹方、微软雅黑及系统无衬线字体；行情数字采用等宽数字。现有衬线标题保留品牌气质。控件文字 13–14px，辅助标签 11–12px，菜单选项 14px。普通文字对比度至少 4.5:1；弱化文字不可用于可选项正文。

## 控件与状态

- 筛选器使用 `src/components/Select.tsx`，颜色由 `select.css` 的语义变量管理。避免各页面单独重写菜单。
- 触发按钮及菜单选项至少高 44px；间距采用 4/8/12/16/24px，相关筛选器间距 10px。
- 控件圆角 6px，弹层圆角 8px。菜单必须使用不透明背景。
- 选中项同时显示勾号和强调底色；悬停、键盘活动项使用边框及独立底色；焦点显示 2px 实线外框。
- 普通可选项不使用透明度模拟禁用。禁用状态只用于实际不可执行的操作。
- 下拉菜单渲染到 body，避免被表格容器裁切；保持在视口内，空间不足时向上展开。

## 布局与交互

页面服务于“找物品 → 筛选变体 → 比价 → 查看挂单”。保留魔兽物品图标、品质色和金色操作，采用单一全宽工作区，不使用宣传首屏、成功状态徽章、重复统计卡和常驻侧栏。未开放的账户入口不占据主要导航。

设计基线：浅底 `#f5f6f8`、白色工作区 `#ffffff`、正文 `#1c2028`、辅助文字 `#646b77`、金色 `#a67600`、边线 `#e6e9ef`。深色沿用现有控件语义色。品牌保留衬线字；列表、筛选和说明统一使用系统中文无衬线字体。主表正文 13px、说明 11–12px，价格与数量右对齐且保持等宽数字。

```text
桌面  [品牌]                                       [刷新] [主题]
      [全部物品] [12.1 团本装绑]                  数据时间
      [搜索名称或 ID                 ] [排序 ▾] [每页 ▾]
      [难度 ▾] [属性 ▾] [插槽 ▾] [额外属性 ▾]（装绑视图）
      当前结果 / 搜索条件
      全宽行情列表
      分页

手机  [品牌]                                  [刷新] [主题]
      [全部物品] [12.1 团本装绑]
      数据时间
      [搜索名称或 ID                              ]
      [排序 ▾]                        [每页 ▾]
```

审查：不新增概览卡和装饰统计；移除侧栏后，装绑入口在手机和桌面始终位于列表上方。数据时间是判断报价时效的必要信息，保留；成功状态无需占空间，错误与不完整数据在相关区域明确说明。详情先显示挂单，“历史价格”默认折叠，展开才请求历史数据。

标题及字段左对齐，价格和数量右对齐。键盘支持方向键、Home/End、Enter/Space 确认、Escape 取消及 Tab 离开；点击外部关闭。选择排序或每页条数后回到第一页，保留搜索和筛选条件。

## 发布检查

团本装绑的难度、属性、插槽、额外属性筛选紧跟列表工具栏，使用同一套 Select。680px 及以上四列，较窄屏幕两列；以已有金色和品质色表达选择，避免新增装饰卡片。副属性保留前后顺序。筛选先作用到同一条挂单，再汇总最低价和数量；弹窗沿用筛选。历史行情若未筛选，必须明确标注范围。缺失物品链接不得当成“无插槽／无额外属性”。

检查深色与浅色、桌面与 375px 手机宽度、键盘焦点、菜单边界、排序及分页请求。旧版 Safari 的查询参数不能依赖 `URLSearchParams.size`。尊重减少动态效果及系统高对比度设置。

图标审查必须逐项检查工具栏按钮、分类入口和弹窗图标。图标应在自身容器内水平及垂直居中；通过浏览器实际计算布局与截图同时验证。文字排版规则应限定在文字容器内，禁止用 `.metric-card span` 这类宽泛选择器覆盖图标容器的 grid/flex 布局。

物品简介采用可选 Wowhead 官方外链提示，仅由访客浏览器加载官方脚本和数据。失败、加载中及缺失结果不显示浮层；不可增加服务端代取、代理或持久缓存。禁止外部脚本重命名物品、改写品质色或新增图标。手机端保留标准外链和本地挂单入口，不启用外部触控遮罩。挂单有完整物品链接时传递真实 bonus、附魔和宝石；汇总物品只链接基础资料，不推测具体变体。

挂单详情默认每页 25 条，可切换 50／100 条和输入页码跳转。底部固定分页区显示当前范围与总条数；翻页保留上一页内容并显示加载状态，等待时禁用重复翻页。关闭弹窗取消挂单与历史请求，已读取页在一分钟内复用。分页控件至少高 44px，手机换行且不可挤出视口。

金色边线与金色正文分开管理：正文使用 `--gold-text`。物品品质保留色相，深色主题提高明度，难度徽章按主题调整文字色，避免将浅色背景的深紫文字直接用于深色背景。

## 顶部工具栏修订

市场选择与历史快照放在分类下方的紧凑同行，手机也尽量保持两列。混合市场不显示全局更新时间；每条报价显示本服实际采集时间及距今时长。选定市场后标题显示该快照的“采集于”，不把历史快照称为最新。已移除的市场或快照必须提供明确错误和重置入口。详情里的跨服报价、历史均默认折叠，展开再请求，并沿用装备筛选；历史图在手机按可用宽度布局，避免将整张桌面图缩小到文字不可读。

分类改成紧凑分段按钮，不使用皇冠图标或粗下划线；时间仅显示“更新于 MM/DD HH:mm”，完整日期保留在悬停说明。桌面及平板搜索、排序和每页条数同一行；640px 以下搜索独占一行，排序和每页条数均匀排满下一行，不留一侧空白。分类与短时间同排，极窄宽度允许自然换行。

装绑筛选使用 Select 的 `appearance="filter"`：默认无外框，字段名＋“不限”，选中后轻微强调；保留 44px 触控目标与完整无障碍名称。最多四个紧凑筛选占 652px，不拉成长条表单。680px 以下改两列。删除常驻解释，仅在有条件时显示“已筛选”和“清除”。中性底色让游戏图标与报价成为主要视觉；价格不允许拆行。审查 708px、375px 和桌面，以及深浅主题。
