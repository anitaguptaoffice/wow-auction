# 艾泽拉斯交易所 UI 规范

采用 frontend-design skill，围绕魔兽拍卖行的查价任务使用单一暖棕、米色主题，参考传统魔兽论坛的色彩气质。物品品质色保留游戏语义。取消黑白切换，不读取系统深浅偏好；旧主题选择应自动清除。

## 视觉基线

| 用途 | 颜色 |
| --- | --- |
| 胡桃棕顶栏 | `#49372b` |
| 沙褐色页面底 | `#e2d6bf` |
| 米色工作区 | `#f3ead7` |
| 表头、展开区 | `#e9dcc2` |
| 深棕正文 | `#382c23` |
| 辅助文字 | `#6e5b49` |
| 古铜色选择与操作 | `#87562e` |
| 控件、菜单背景 | `#f8f1e3` |

品牌保留宋体气质的衬线字，列表、控件与说明使用苹方、微软雅黑及系统无衬线字体。主表正文 13px、物品名 14px、说明 11–12px，价格与数量右对齐并保持等宽数字。普通文字对比度至少 4.5:1；焦点使用实线棕色外框。暖色只作用于界面，绿、蓝、紫、橙等品质色及货币颜色继续表达游戏含义。

设计选择：深棕顶栏提供清楚的页面边界，米色表格承载物品和价格，表头及展开区使用更深一档的米色。维持紧凑查价工作区，不增加纹理、装饰卡片或宣传首屏。

## 控件与状态

- 筛选器使用 `src/components/Select.tsx`，颜色由 `select.css` 的语义变量管理。避免各页面单独重写菜单。
- 触发按钮及菜单选项至少高 44px；间距采用 4/8/12/16/24px，相关筛选器间距 10px。
- 控件圆角 6px，弹层圆角 8px。菜单必须使用不透明背景。
- 选中项同时显示勾号和强调底色；悬停、键盘活动项使用边框及独立底色；焦点显示 2px 实线外框。
- 普通可选项不使用透明度模拟禁用。禁用状态只用于实际不可执行的操作。
- 下拉菜单渲染到 body，避免被表格容器裁切；保持在视口内，空间不足时向上展开。

## 布局与交互

页面服务于“找物品 → 筛选变体 → 比价 → 查看挂单”。保留魔兽物品图标、品质色和金色操作，采用单一全宽工作区，不使用宣传首屏、成功状态徽章、重复统计卡和常驻侧栏。未开放的账户入口不占据主要导航。

```text
桌面  [品牌]                                       [刷新]
      [全部物品] [12.1 团本装绑]                  数据时间
      [搜索名称或 ID                 ] [排序 ▾] [每页 ▾]
      [难度 ▾] [属性 ▾] [插槽 ▾] [额外属性 ▾]（装绑视图）
      当前结果 / 搜索条件
      全宽行情列表
      分页

手机  [品牌]                                  [刷新]
      [全部物品] [12.1 团本装绑]
      数据时间
      [搜索名称或 ID                              ]
      [排序 ▾]                        [每页 ▾]
      装绑筛选（两列）
      当前结果 / 紧凑物品报价 / 分页
```

审查：不新增概览卡和装饰统计；移除侧栏后，装绑入口在手机和桌面始终位于列表上方。数据时间是判断报价时效的必要信息，保留；成功状态无需占空间，错误与不完整数据在相关区域明确说明。详情先显示挂单，“历史价格”默认折叠，展开才请求历史数据。

标题及字段左对齐，价格和数量右对齐。键盘支持方向键、Home/End、Enter/Space 确认、Escape 取消及 Tab 离开；点击外部关闭。选择排序或每页条数后回到第一页，保留搜索和筛选条件。

行情整行可点击：普通物品进入该行来源服的挂单，全部市场中的团本装绑展开各服报价；选定市场或历史快照时进入对应快照的挂单。名称和图标保留 Wowhead 外链，不触发行操作；右侧按钮执行同一操作且只触发一次。整行保留表格语义，支持 Tab 聚焦及 Enter/Space 操作；读取中禁用，拖选文字不打开详情。

挂单弹窗支持点击外部遮罩关闭，鼠标和触控一致。点击内部留白或从弹窗内拖选到外部不关闭；右键不关闭。Escape 与关闭按钮继续可用，关闭后取消未完成的挂单和历史请求。

历史折线保留真实时间间隔，不为避免拥挤而等距重排或删掉快照。时间轴按可用像素显示 2–4 个等距刻度，窄屏日期与时刻分两行；价格改用纵轴刻度，不逐点堆放文字。采集点使用小圆点，仅突出当前点；图下显示该点完整时间、服务器及精确金银铜价格。支持悬停、触控点选、前后按钮和方向键，密集或重合点仍可逐个查看。缺价断线按服务器单独处理，禁止跨缺口或跨服连接；侧边最新统计与选中点报价明确区分。

## 发布检查

全部市场按同区域、同市场范围、同物品及档位归并为一行，筛选与归并先于排序、分页。最低单价与最低一口价分别标明来源服；挂单和数量标为各服合计，副属性组合跨服去重。展开各服报价时保留每服实际采集时间，选择报价后查看该服原始挂单。不同区域与市场范围不得混合；选定服务器或历史快照时继续显示单服数据。

列表的“副属性组合”只按已识别的有序副属性对去重，并沿用当前插槽及额外属性筛选。完整物品链接去重数 `variantCount` 包含其他 bonus 差异，禁止将它标成属性组合数；未识别的属性不作为新的一种组合。

团本装绑的难度、属性、插槽、额外属性筛选紧跟列表工具栏，使用同一套 Select。680px 及以上四列，较窄屏幕两列；以已有金色和品质色表达选择，避免新增装饰卡片。副属性保留前后顺序。筛选先作用到同一条挂单，再汇总最低价和数量；弹窗沿用筛选。历史行情若未筛选，必须明确标注范围。缺失物品链接不得当成“无插槽／无额外属性”。

检查暖棕主题、桌面与 375px 手机宽度、键盘焦点、菜单边界、排序及分页请求。旧版 Safari 的查询参数不能依赖 `URLSearchParams.size`。尊重减少动态效果及系统高对比度设置。

图标审查必须逐项检查工具栏按钮、分类入口和弹窗图标。图标应在自身容器内水平及垂直居中；通过浏览器实际计算布局与截图同时验证。文字排版规则应限定在文字容器内，禁止用 `.metric-card span` 这类宽泛选择器覆盖图标容器的 grid/flex 布局。

物品简介采用可选 Wowhead 官方外链提示，仅由访客浏览器加载官方脚本和数据。失败、加载中及缺失结果不显示浮层；不可增加服务端代取、代理或持久缓存。禁止外部脚本重命名物品、改写品质色或新增图标。手机端保留标准外链和本地挂单入口，不启用外部触控遮罩。挂单有完整物品链接时传递真实 bonus、附魔和宝石；汇总物品只链接基础资料，不推测具体变体。

挂单详情默认每页 25 条，可切换 50／100 条和输入页码跳转。底部固定分页区显示当前范围与总条数；翻页保留上一页内容并显示加载状态，等待时禁用重复翻页。关闭弹窗取消挂单与历史请求，已读取页在一分钟内复用。分页控件至少高 44px，手机换行且不可挤出视口。

古铜色边线与正文分开管理：正文使用 `--gold-text`。物品品质保留色相，辅助文字、品质名及难度徽章在米色背景上都应保持清晰。

## 顶部工具栏修订

市场选择与历史快照放在分类下方的紧凑同行，手机也尽量保持两列。混合市场不显示全局更新时间；每条报价显示本服实际采集时间及距今时长。选定市场后标题显示该快照的“采集于”，不把历史快照称为最新。已移除的市场或快照必须提供明确错误和重置入口。详情里的跨服报价、历史均默认折叠，展开再请求，并沿用装备筛选；历史图在手机按可用宽度布局，避免将整张桌面图缩小到文字不可读。

分类改成紧凑分段按钮，不使用皇冠图标或粗下划线；时间仅显示“更新于 MM/DD HH:mm”，完整日期保留在悬停说明。桌面及平板搜索、排序和每页条数同一行；640px 以下搜索独占一行，排序和每页条数均匀排满下一行，不留一侧空白。分类与短时间同排，极窄宽度允许自然换行。

装绑筛选使用 Select 的 `appearance="filter"`：默认无外框，字段名＋“不限”，选中后轻微强调；保留 44px 触控目标与完整无障碍名称。最多四个紧凑筛选占 652px，不拉成长条表单。680px 以下改两列。删除常驻解释，仅在有条件时显示“已筛选”和“清除”。中性底色让游戏图标与报价成为主要视觉；价格不允许拆行。审查 708px、375px 和桌面，以及旧主题偏好迁移。
