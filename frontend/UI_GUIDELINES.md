# 艾泽拉斯交易所 UI 规范

采用 frontend-design skill，围绕魔兽拍卖行的查价任务维护黑金视觉。金色用于当前选择和可执行操作，物品品质色保留游戏语义。装饰不应降低行情表格的可读性。

## 视觉基线

| 用途 | 深色 | 浅色 |
| --- | --- | --- |
| 控件背景 | `#1b2027` | `#fffefb` |
| 菜单背景 | `#20262e` | `#fffefb` |
| 主文字 | `#f4f1e9` | `#262b33` |
| 辅助文字 | `#b4bac4` | `#646b77` |
| 控件边框 | `#586171` | `#b9b2a5` |
| 选择强调 | `#f1cc72` | `#775400` |

正文与控件使用苹方、微软雅黑及系统无衬线字体；行情数字采用等宽数字。现有衬线标题保留品牌气质。控件文字 13–14px，辅助标签 11–12px，菜单选项 14px。普通文字对比度至少 4.5:1；弱化文字不可用于可选项正文。

## 控件与状态

- 筛选器使用 `src/components/Select.tsx`，颜色由 `select.css` 的语义变量管理。避免各页面单独重写菜单。
- 触发按钮及菜单选项至少高 44px；间距采用 4/8/12/16/24px，相关筛选器间距 10px。
- 控件圆角 6px，弹层圆角 8px。菜单必须使用不透明背景。
- 选中项同时显示勾号和强调底色；悬停、键盘活动项使用边框及独立底色；焦点显示 2px 实线外框。
- 普通可选项不使用透明度模拟禁用。禁用状态只用于实际不可执行的操作。
- 下拉菜单渲染到 body，避免被表格容器裁切；保持在视口内，空间不足时向上展开。

## 布局与交互

```text
桌面  [物品市场 / 条目数]            [排序 价格最低 ▾] [每页 20 条 ▾]
手机  [物品市场 / 条目数]
      [排序 价格最低 ▾]             [每页 20 条 ▾]
```

标题及字段左对齐，价格和数量右对齐。手机筛选器保持同一行，菜单宽度不超过视口。键盘支持方向键、Home/End、Enter/Space 确认、Escape 取消及 Tab 离开；点击外部关闭。选择排序或每页条数后回到第一页，保留搜索和筛选条件。

## 发布检查

检查深色与浅色、桌面与 375px 手机宽度、键盘焦点、菜单边界、排序及分页请求。旧版 Safari 的查询参数不能依赖 `URLSearchParams.size`。尊重减少动态效果及系统高对比度设置。

图标审查必须逐项检查摘要卡片、工具栏按钮、侧栏入口和弹窗图标。图标应在自身容器内水平及垂直居中；通过浏览器实际计算布局与截图同时验证。文字排版规则应限定在文字容器内，禁止用 `.metric-card span` 这类宽泛选择器覆盖图标容器的 grid/flex 布局。

物品简介采用可选 Wowhead 官方外链提示，仅由访客浏览器加载官方脚本和数据。失败、加载中及缺失结果不显示浮层；不可增加服务端代取、代理或持久缓存。禁止外部脚本重命名物品、改写品质色或新增图标。手机端保留标准外链和本地挂单入口，不启用外部触控遮罩。挂单有完整物品链接时传递真实 bonus、附魔和宝石；汇总物品只链接基础资料，不推测具体变体。
