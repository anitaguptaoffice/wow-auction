# 魔兽世界拍卖行扫描 — 外部自动化开发计划（已定稿 v1）

本文档描述 **Windows** 下用 **Go** 实现「战网 → 魔兽 → 多角色循环：选角 → 拍卖行 → **插件扫完并小退** → 选下一角」的自动化，以及与 **游戏内插件** 的职责边界。  
**内部工具，合规与封号风险由使用方自担。**

---

## 1. 已定稿需求摘要


| 项                       | 决策                                                                                                                                                                                                                                                                                                                                                              |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 战网登录                    | **不自动填密码**；假定 **战网已记住登录**，脚本负责 **启动战网 + 固定位置点击**（如「进入游戏」）。                                                                                                                                                                                                                                                                                                      |
| 多角色                     | **小退到选角 → 按配置选角 → 进世界 → 再扫**；**角色顺序写在配置**里（列表变动只改配置）；支持 **只扫单个角色** 或 **按列表全部扫描**。选角定位可用 **Home 回到列表初始位置** 再按配置步进（与「下箭头次数」等可组合，以实现为准）。                                                                                                                                                                                                                           |
| 小退                      | **环境不支持插件直接调用 Blizzard `logout`**。扫完后由 **插件生成/展示自定义 UI**，由 **Go 用 OpenCV 模板（及 ROI）识别该 UI 上的状态**，在条件满足时 **SendInput 点击** 完成「返回角色」链路；**UI 内各步**同样用 **模板匹配** 判定（与战网/选角一致的技术栈）。具体有几步、何模板，**上机标定**。                                                                                                                                                                  |
| 扫描完成 / 等待选角             | **Go 不读内存**；**已开始扫描 / 扫描完成** 等进度 **仅以插件自有 UI 上的屏显为准**，用 **OpenCV 模板** 识别（**插件 UI 定稿后** 为各态配 ROI）。**无单独「打开插件主面板」热键**：**宏 `/tar` 拍卖行 NPC** → **交互键打开拍卖行** 后，插件 **自动** 触发/展示 UI，Go 再在该面板上轮询直至 **「扫描完成」**，随后进入登出 UI 链。**总死线** `scan_trigger_ts`：**仍以「`AH_OPEN` 成功」（拍卖已打开）写入**；从该时刻起若在 `max_wait_since_scan_trigger` 内未回到 **选角** → 按 §5.2 杀进程并全流程重试 **同一角色**。 |
| 拍卖行开启（`AH_OPEN`）        | 游戏内 **仅需配置两项**：**绑定拍卖行 NPC 的 tar 宏所在键**，以及 **与目标交互键**（与游戏键位设置一致）。**无** 第三颗「开插件面板」键。                                                                                                                                                                                                                                                                             |
| 视觉判据                    | **OpenCV**：模板匹配 + 颜色/采样为主（战网按钮状态、选角、进世界等）；ROI 与模板随配置绑定。                                                                                                                                                                                                                                                                                                         |
| 进世界判定                   | **可配置按键**（宏/技能所在键位）；用 **该键位在动作条上的 ROI + 模板/颜色** 判定是否已进世界（与按键配置一一对应）。                                                                                                                                                                                                                                                                                            |
| 失败处理                    | **写日志**；按 **当前 FSM 状态** 做 **恢复/回滚**（具体转移表见 §5.2，首版可简化为少量固定动作）。                                                                                                                                                                                                                                                                                                  |
| 显示                      | **魔兽：全屏无边框**；**战网：全屏**，定点按钮点击位置 **固定**（同一台机器、固定分辨率与系统缩放）。                                                                                                                                                                                                                                                                                                       |
| 显示器                     | **单配置**：固定 **分辨率 + 缩放**，首版 **不做多档自适应**；战网与魔兽均在 **同一套桌面几何** 下校准坐标。                                                                                                                                                                                                                                                                                               |
| Go 依赖                   | **怎么方便怎么来**（允许 **cgo + OpenCV** 等）。                                                                                                                                                                                                                                                                                                                             |
| 代码位置                    | 仓库 `automation/wow-runner/`（Go module + 示例配置）。                                                                                                                                                                                                                                                                                                              |
| 最后一角结束后                 | **直接 `taskkill` 结束 `Wow.exe`**（此时已在选角，**插件数据已落盘**；不再依赖游戏内正常退出）。                                                                                                                                                                                                                                                                                                 |
| `WAIT_PLUGIN_LOGOUT` 超时 | **不用 /reload**；**终止整个魔兽进程** → **从战网/进程检测起重新跑全流程** → **仍从当前异常角色重试**（不推进角色索引）。                                                                                                                                                                                                                                                                                    |
| 插件无法小退                  | **Go 无法区分**「插件失败」与「仍在扫」；超时即按 `scan_trigger_ts` 策略走 §5.2。若 **自定义登出 UI** 某步模板长期不匹配，同样**在总超时内**未回到选角 → 同 §5.2。可选：**备选键序**（见 [FLOW_AND_EXCEPTIONS.md §7](FLOW_AND_EXCEPTIONS.md)）。                                                                                                                                                                              |


### 1.1 摘要（与上表一致，便于实现对照）

1. **关客户端**：最后一角流程结束后 **直接杀 `Wow.exe`**。
2. **角色范围**：配置中 **角色列表 + 模式**（`single` / `all`）。**首轮进选角**、以及 **异常杀进程后全流程重启再进选角**：**Home 回顶再定位**；**插件正常小退回到选角后换下一角**：**仅下滑等步进**（不再 Home，除非配置另行规定）。
3. **按键与图像**：**进世界**、**拍卖** 等均为 **可配置键位 + ROI 模板**；拍卖 **仅 tar 宏键 + 交互键**（见上表）。
4. **插件**：**UI 定稿** 后标模板；**开拍卖后插件自动出 UI**；**扫完** 再 **登出 UI**；**无直接 logout**（见 §4.1）。
5. **等待选角超时**：总时钟为 `scan_trigger_ts`（**「`AH_OPEN` 成功」**）；中间用 **插件 UI 模板** 判断扫完，再点登出；超时则杀进程全流程重来、**同角重试**。

## 2. 目标与范围


| 目标    | 说明                                                                                                              |
| ----- | --------------------------------------------------------------------------------------------------------------- |
| 战网自动化 | 启动战网、在**全屏固定布局**下 **像素级点击** 若干按钮；**是否已开游戏**以 **`Wow.exe` 进程** 为准。                                               |
| 进程检测  | `Battle.net` / `Wow.exe` 进程名可配置；已存在则**不重复启动**（除非配置强制）。                                                          |
| 游戏内流程 | **首轮/重启后**：`CHAR_SELECT`（Home+定位）→ 进世界 → 开拍卖（插件自动扫）→ 等选角；**正常换角**：`CHAR_SELECT_AGAIN`（下滑）→ …                    |
| 状态管理  | **FSM**，每步超时、重试；失败记录日志并进入 **回滚分支**。                                                                             |
| 视觉    | 固定分辨率/缩放下 **OpenCV 模板 + 颜色/采样** 为主；战网/选角/游戏内 **不同 ROI**；详见 [FLOW_AND_EXCEPTIONS.md §2](FLOW_AND_EXCEPTIONS.md)。 |
| 插件    | Replicate、SV；**UI 上展示**已开始扫描、扫描完成等；**开拍卖后自动触发**；扫完后 **登出用 UI**；Go **全程模板 + 点击**；**不读内存**。                       |


**不在首版范围**：多账号轮换、Mac、分辨率热切换。

## 4. FSM（首版定稿）

**核心变化**：**不读内存**；**扫描进度与完成** 看 **插件 UI 模板**。**`AH_OPEN`**：**tar 宏 + 交互** 开拍卖 → 插件 **自动** 出 UI 并扫。**无单独「开插件面板」键**。总**死线**从 `scan_trigger_ts`（**「`AH_OPEN` 成功」**）起算，见 §1 表。

**为何保留 `CHAR_SELECT` 与 `CHAR_SELECT_AGAIN` 两状态**：**选角操作不同**——首轮与异常重启后需 **Home 再定位**；插件正常小退后换角只需 **下滑步进**，合并成同一状态会把分支写乱，故拆成两个状态 ID。


| 状态 ID                | 含义           | Go 侧动作                                                                                   | 成功判据                               | 超时建议（可配置）                              |
| -------------------- | ------------ | ---------------------------------------------------------------------------------------- | ---------------------------------- | -------------------------------------- |
| `INIT`               | 初始化          | 读配置                                                                                      | —                                  | —                                      |
| `BNET_START`         | 战网           | 若进程无则启动；若 Wow 无则点击「进入游戏」                                                                 | `Wow.exe` 存在                       | 120s                                   |
| `WOW_FOREGROUND`     | 魔兽前台         | 激活魔兽窗口                                                                                   | HWND 成功                            | 15s                                    |
| `CHAR_SELECT`        | 选角（首轮 / 重启后） | **Home 回顶** + 按配置定位到 **角色[i]**（`single`/`all` 见配置）                                       | 模板：**选角界面**（进入游戏前）                 | 60s                                    |
| `ENTER_WORLD`        | 进世界          | 发送进入游戏/确认                                                                                | 模板：**配置的进世界按键 ROI**（动作条格等）出现且与选角互斥 | 120s                                   |
| `AH_PREP`            | 准备开拍卖        | （可选）短延时                                                                                  | —                                  | 3s                                     |
| `AH_OPEN`            | 开拍卖          | **配置键**：先 **tar 拍卖行 NPC 宏**，再 **交互键** 开拍卖；成功后 **写入 `scan_trigger_ts`**；插件 **自动** 出 UI 并扫 | 模板：拍卖行 / 插件 UI 出现（可选）              | 30s                                    |
| `WAIT_PLUGIN_LOGOUT` | 等选角          | **插件 UI 已在开拍后出现**：模板 **已开始扫描 → 扫描完成** → **登出 UI 模板 + 点击链** → **选角**（见 §4.1）              | 模板：**选角界面** 再次出现                   | **自 `scan_trigger_ts` 起算**的长超时（如 600s） |
| `CHAR_SELECT_AGAIN`  | 再次选角（正常小退后）  | 已在选角；列表 **顺序相邻**：换下一角 **按一次 ↓**，到 **角色[i+1]**，**不 Home**                                 | 同上                                 | 60s                                    |
| `ROUND_DONE`         | 一轮扫完         | 最后一角已在选角 → **`taskkill Wow.exe`**                                                        | —                                  | —                                      |
| `FAILED`             | 失败           | 打日志、执行回滚                                                                                 | —                                  | —                                      |


- `scan_trigger_ts`：在 **「`AH_OPEN` 成功」**判据满足时（拍卖已打开，视为插件自动扫描已启动）**写入**；`WAIT_PLUGIN_LOGOUT` 内若 `now - scan_trigger_ts` 超过配置阈值仍未识别选角 → **§5.2**。  
- **多角色循环**：`WAIT_PLUGIN_LOGOUT` 成功且 **还有下一角色** → `CHAR_SELECT_AGAIN`（下滑）→ `ENTER_WORLD` → …  
- **全流程重启后**（杀进程再起）：下一进入选角 → `CHAR_SELECT`（Home + 定位到当前重试角 **i**）。  
- **最后一角扫完**：插件小退到选角后 → `ROUND_DONE` → **`taskkill`**，不再进世界。

### 4.1 `WAIT_PLUGIN_LOGOUT` 内部子步骤（**非**单独顶层 FSM 状态）

实现时可在 `WAIT_PLUGIN_LOGOUT` 内做 **子状态机** 或 **有序检查表**。**模板与 ROI 在插件 UI 定稿后** 一次性标定（与 [FLOW_AND_EXCEPTIONS.md §2.4–§2.5](FLOW_AND_EXCEPTIONS.md) 一致）。

1. **「`AH_OPEN` 成功」**（**tar 宏 + 交互**）→ 写入 `scan_trigger_ts`（总超时起点）；**拍卖打开后插件 UI 自动出现**，插件 **自动开始扫描**。
2. **插件 UI 模板**（无需再发「开面板」键）：识别 **已开始扫描**、**扫描中**（若需）、**扫描完成**（以定稿 UI 为准）；**「扫描完成」出现前** 不进入登出点击链。
3. **登出 UI**：扫描完成后插件展示 **登出/确认用 UI**；**每步先模板、后点击**，直至 **选角界面**（与 [FLOW_AND_EXCEPTIONS.md §2.2](FLOW_AND_EXCEPTIONS.md) 一致）。
4. **战斗**：本流程 **假定始终不在战斗状态**；**Secure** 相关限制 **首版不单独处理**。

**原则**：总时长仍受 `scan_trigger_ts` + `max_wait_since_scan_trigger` 约束（见 [FLOW_AND_EXCEPTIONS.md §2.6](FLOW_AND_EXCEPTIONS.md)）。

完整流程与异常矩阵见 [FLOW_AND_EXCEPTIONS.md](FLOW_AND_EXCEPTIONS.md)。

## 5. 异常处理

### 5.1 原则

- **日志**：所有状态迁移、重试、杀进程、`scan_trigger_ts`、模板/视觉判据、错误与恢复均须记录，**与 [LOGGING_SPEC.md](LOGGING_SPEC.md) 一致**，便于端到端测试。
- **仅日志 + 非零退出码**（首版无托盘弹窗，除非后续加）。
- 每步：**超时 `T`**、**重试 `R`**、超过则 **进入 `FAILED`** 或 **预定义回滚状态**。
- **全局熔断**：同一状态连续失败 `M` 次 → `FAILED`。

### 5.2 回滚（首版简化，待实现时细化）


| 当前状态（失败时）                     | 建议恢复动作（示例）                                                                                                                                                            |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BNET_START`                  | 重试启动战网；kill 残留进程（可选，危险，默认关）                                                                                                                                           |
| `CHAR_SELECT` / `ENTER_WORLD` | `Esc` 若干次 → 回到已知屏 → 重试键序                                                                                                                                              |
| `AH_OPEN`                     | `Esc` 关 UI → 重触发宏                                                                                                                                                     |
| `WAIT_PLUGIN_LOGOUT`          | **自 `scan_trigger_ts` 起**超时仍无选角：记 **PLUGIN_STUCK** → **结束 `Wow.exe` 进程** → 从 `BNET_START`（或等价入口）**重新拉起全流程** → **角色索引不变**，重试当前角；超过 **每角最大重试次数** 则 `FAILED`（避免无限杀进程循环）。 |


**不使用 /reload** 作为该状态的恢复手段（与「整进程重启」策略一致）。

## 6. 战网自动化（定稿）

- **全屏 + 固定分辨率与缩放**，按钮 **绝对坐标** 写入配置（首版简单；后续可加比例坐标）。
- **流程**：若 **无 Wow 进程** → 确保战网开 → **点击「进入游戏」**（坐标可配置）；若 **已有 Wow** → 跳过点击。
- **战网进程名 / 安装路径**：可配置。

### 6.1 拍卖行开启（游戏内，`AH_OPEN`）

- **仅需两项键位配置**：**拍卖行 NPC 的 `/tar` 宏** 所绑定的键，以及 **与目标交互**（开拍卖）的键，须与游戏 **按键设置** 一致。
- **无** 单独的「打开插件主面板」热键；**交互打开拍卖行后**，插件 **自动** 触发扫描并 **显示** 用于监控的 UI（与 §1、§4 一致）。

## 7. 插件侧开发任务（与 Go 并行）

1. **UI 定稿**（**先于** Go 模板大规模标定）：面板上 **清晰可见**「已开始扫描」「扫描中」「扫描完成」等状态（文案或控件），供 **OpenCV 模板** 识别；**扫描完成** 后再 **展示登出用 UI**（无直接 `logout` API）。
2. **与 `AH_OPEN` 衔接**：玩家用 **宏 tar NPC + 交互开拍卖** 后，插件 **自动** 进入扫描并 **展示** 上述 UI（**无需**再注册「开面板」全局热键）。
3. **无直接 `logout`**：登出链上 **按钮/确认** 由 Go **模板 + 点击**；首版 **假定不在战斗**，**Secure** 不作为阻塞项。
4. Go **不读内存**；总超时仍以 `scan_trigger_ts` + 选角模板 为准；可选 **备选键序**（见 FLOW §7）。
5. （可选）**日志**：`print` 调试信息，便于对照 Go 日志。
